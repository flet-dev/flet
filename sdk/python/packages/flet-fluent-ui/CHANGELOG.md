## 1.1.3

### Added

- Initial release: controls styled after Microsoft's [Fluent Design](https://fluent2.microsoft.design) for Windows, built on the Flutter [`fluent_ui`](https://pub.dev/packages/fluent_ui) package, with `Theme` accent colors and the `FluentIcons` icon set. Includes `Button`, `FilledButton`, `OutlinedButton`, `HyperlinkButton`, `IconButton`, `ToggleButton`, `Checkbox`, `ToggleSwitch`, `RadioGroup`, `Slider`, `TextBox`, `ComboBox`, `ProgressBar`, `ProgressRing`, `InfoBar`, `Expander`, `Card`, `Tooltip`, `ContentDialog`, `PasswordBox`, `NumberBox`, `AutoSuggestBox`, `InfoLabel`, `RatingBar`, `Divider`, `ListTile`, `InfoBadge`, `DatePicker`, `TimePicker`, `CalendarView`, `CalendarDatePicker`, `ColorPicker`, `Flyout`, `TeachingTip`, `ContextMenu`, `MenuBar`, `DropDownButton`, `SplitButton` and `CommandBar` by @InesaFitsner.
