# Flet Notifications

`Notifications` service for Flet apps. Show, schedule and cancel system notifications on Android, iOS, macOS, Windows, Linux and Web via the [`flutter_local_notifications`](https://pub.dev/packages/flutter_local_notifications) Flutter plugin.

> **[Try Flet online in Flet Studio](https://studio.flet.dev/?utm_source=pypi&utm_medium=readme&utm_campaign=flet-notifications)**
>
> Prototype your Flet app interface in the browser, then add local notifications in your local project. Write your own Python code or get help from the AI agent.
