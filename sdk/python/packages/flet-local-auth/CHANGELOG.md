## 1.0.0

### Added

- Initial release: a `LocalAuthentication` service for on-device biometric and credential authentication on Android, iOS, macOS and Windows, wrapping the [`local_auth`](https://pub.dev/packages/local_auth) Flutter plugin. Linux and Web are not supported ([#3192](https://github.com/flet-dev/flet/issues/3192), [#6823](https://github.com/flet-dev/flet/pull/6823)) by @mccre110.
