# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## 0.85.0

### Changed

- Updated the Flutter [`camera`](https://pub.dev/packages/camera) plugin to 0.12 ([#6406](https://github.com/flet-dev/flet/pull/6406)) by @FeodorFitsner.

## 0.83.0

### Changed

- `CameraPreviewSize` and `CameraDescription` are `@ft.value` types ([#6296](https://github.com/flet-dev/flet/pull/6296)) by @FeodorFitsner.

## 0.81.0

### Added

- Initial release: a `Camera` control that shows a live camera preview, takes pictures, records videos and streams image frames, wrapping the Flutter [`camera`](https://pub.dev/packages/camera) plugin ([#6190](https://github.com/flet-dev/flet/pull/6190)) by @FeodorFitsner.
