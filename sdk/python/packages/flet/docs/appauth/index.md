# AppAuth

Native OAuth 2.0 authorization-code + PKCE for Android and iOS via the
`flet-appauth` extension, wrapping
[`flutter_appauth`](https://pub.dev/packages/flutter_appauth).

`AppAuth` performs **authorize + redirect capture only**. Token exchange,
user/group loading, and [`Page.on_login`][flet.Page.on_login] remain in Python
([`Page.login`][flet.Page.login] / [`AuthorizationService`][flet.auth.authorization_service.AuthorizationService]).

On Android/iOS, [`page.login()`][flet.Page.login] soft-imports this package
automatically. Install it before calling `page.login` on mobile.

```bash

```
///
/// tab | pip
```bash
pip install flet-appauth

pip install 'flet[appauth]'
```
///

### Build redirect scheme

Configure an **AppAuth-specific** redirect scheme (not `tool.flet.deep_linking`):

```toml
[tool.flet.appauth]
redirect_scheme = "myapp"
```

Or:

```bash
flet build apk --appauth-redirect-scheme myapp
```

Register the same scheme with your IdP, e.g. `myapp://oauth-callback`, and set
`OAuthProvider.redirect_url` to that URL.

PKCE on mobile is generated by AppAuth. Provider `code_verifier` /
`code_challenge` fields are for **web** only and are ignored on Android/iOS.

Web-only `page.login` parameters (`on_open_authorization_url`,
`complete_page_html`, `redirect_to_page`) are ignored on mobile.
